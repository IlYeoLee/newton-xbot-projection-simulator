## 1. 시스템 개요

```
[무릎 IMU] ──노이즈+지연──▶ [칼만 필터] ──추정값──▶ [스프링-댐퍼] ──명령──▶ [서보 짐벌]
                                                                                    │
                                                                              [빔 프로젝터]
                                                                                    │
                                                                              [바닥 투사면]
```

| 블록 | 역할 | 알고리즘 |
|---|---|---|
| IMU 노이즈 모델 | 실제 센서 불완전성 시뮬레이션 | Gaussian + Random Walk |
| 지연 모델 | 센서→서보 파이프라인 지연 | 원형 버퍼 (Circular Buffer) |
| 칼만 필터 | 노이즈 제거, 위치 추정 | 1D Kalman (position+velocity) |
| 스프링-댐퍼 | 무릎 추종, 흔들림 감쇠 | 2차 ODE (K_s, K_d) |
| 서보 BW 제한 | 서보 물리 한계 반영 | 각속도 클램핑 |

## 2. 투사 기하학

### 2.1 투사각 (Pitch Angle)

무릎 모듈에서 바닥 투사 중심까지의 고도각:

```
θ = arctan(h_knee / d_fwd)
```

- `h_knee`: 무릎 높이 (지면 기준) [m]
- `d_fwd`:  무릎에서 투사 중심까지 수평 거리 [m]
- `θ_target = 52.5°`: 설계 목표 투사각 (45°~60° 범위의 중간값)

### 2.2 이상 투사 거리 (Optimal Forward Distance)

목표 투사각에서 역산한 최적 투사 거리:

```
d_opt = h_knee / tan(θ_target) = h_knee / tan(52.5°) ≈ h_knee × 0.767
```

예: `h_knee = 0.52m` → `d_opt ≈ 0.40m`

### 2.3 투사 중심 위치 (슬라이더 기반)

사용자가 설정한 시작 거리와 깊이로 투사 중심 결정:

```
d_center = floorStart + floorDepth / 2
```

- `floorStart`: 바닥 UI 시작 거리 (무릎 기준) [m]
- `floorDepth`: 바닥 UI 세로 길이 [m]

### 2.4 각도 오차 피드백 보정

현재 투사각과 목표각의 차이로 소량 거리 보정:

```
Δθ = θ_target - θ_current
Δd = clamp(Δθ × 0.008 × h_knee, -0.3, 0.3)   [m]
```

최종 스프링 목표점: `d_spring = d_center + Δd`

### 2.5 몸 방향 인식 (Body-Forward Direction)

모델 쿼터니언에서 월드 전방 벡터 추출:

```
v_fwd = [0, 0, 1] × Q_model    (Mixamo local forward = +Z)
v_fwd.y = 0
v_fwd = normalize(v_fwd)
```

투사 목표점 (월드 좌표):

```
P_target = P_knee + v_fwd × d_spring
```

## 3. 2차 스프링-댐퍼 안정화

실제 서보 짐벌의 물리적 거동을 모델링. 무릎 흔들림을 따라가되 고주파 진동은 감쇠.

### 3.1 운동 방정식

```
a = K_s × (P_target - P_stab) - K_d × v_stab
v_stab += a × dt
P_stab += v_stab × dt
```

| 파라미터 | 값 | 의미 |
|---|---|---|
| K_s | 22 | 스프링 강성 (spring stiffness) |
| K_d | 9  | 감쇠 계수 (damping coefficient) |
| v_max | 3.0 m/s | 속도 클램프 (서보 BW 미설정 시) |

### 3.2 임계 감쇠 조건

진동 없이 가장 빠르게 수렴하는 임계 감쇠:

```
K_d_critical = 2 × √K_s = 2 × √22 ≈ 9.38
```

현재 K_d = 9 ≈ K_d_critical → **거의 임계 감쇠** (약간 미달, 미세 오버슈트 허용)

### 3.3 안정성 조건 (오일러 적분)

명시적 오일러 적분의 안정 조건:

```
dt < 2 / ω_n = 2 / √K_s = 2 / √22 ≈ 0.43s
```

60fps (dt = 0.0167s) → 안정 ✅ (마진 26배)

### 3.4 고유 진동수 & 응답 시간

```
ω_n = √K_s = √22 ≈ 4.69 rad/s ≈ 0.75 Hz
τ_settle ≈ 4 / (ζ × ω_n) = 4 / (1.0 × 4.69) ≈ 0.85s  (2% 기준)
```

## 4. 칼만 필터 추정기

노이즈 섞인 IMU 측정값에서 무릎 위치를 최적 추정. X축과 Z축에 각각 독립 적용.

### 4.1 상태 공간 모델

상태 벡터: `x = [position, velocity]ᵀ`

**시스템 모델:**
```
x_k = F × x_{k-1}     F = [[1, dt],
                              [0,  1 ]]
```

**관측 모델:**
```
z_k = H × x_k + noise     H = [1, 0]
```

### 4.2 예측 단계 (Predict)

```
x̂_k⁻ = F × x̂_{k-1}

P_k⁻ = F × P_{k-1} × Fᵀ + Q

Q = [[Q_pos × dt,      0     ],
     [    0,       Q_vel × dt]]
```

### 4.3 갱신 단계 (Update)

```
y   = z_k - H × x̂_k⁻                    (혁신, Innovation)
S   = H × P_k⁻ × Hᵀ + R                 (혁신 공분산)
K   = P_k⁻ × Hᵀ × S⁻¹                   (칼만 게인)

x̂_k = x̂_k⁻ + K × y                     (상태 갱신)
P_k  = (I - K × H) × P_k⁻               (공분산 갱신)
```

1D 단순화 (스칼라 형태):

```
K₀ = P₀₀ / (P₀₀ + R)     ← 위치 게인
K₁ = P₁₀ / (P₀₀ + R)     ← 속도 게인

pos += K₀ × (meas - pos)
vel += K₁ × (meas - pos)
```

### 4.4 파라미터 튜닝 가이드

| 파라미터 | 기본값 | 높이면 | 낮추면 |
|---|---|---|---|
| Q (프로세스 노이즈) | 0.04 | 빠른 추종, 노이즈 민감 | 느린 추종, 스무딩 |
| R (측정 노이즈) | 0.0009 | 측정 불신, 더 스무딩 | 측정 신뢰, 빠른 반응 |

**규칙:** IMU σ = 3mm → R ≈ (0.003)² = 0.000009

## 5. IMU 노이즈 모델

### 5.1 가속도계 Gaussian 노이즈

```
ε ~ N(0, σ_acc²)
pos_sensed = pos_true + ε
```

Box-Muller 변환으로 생성:
```
ε = √(-2 ln u₁) × cos(2π u₂) × σ_acc
```

### 5.2 자이로 드리프트 (Random Walk)

적분 오류로 인한 위치 드리프트 누적:

```
drift += N(0, 1) × drift_rate × dt × k_scale
pos_sensed += drift
```

- `drift_rate`: 자이로 드리프트율 [°/s]
- `k_scale = 0.0002`: 각도→위치 환산 스케일 (시뮬레이터 조정값)

### 5.3 실제 IMU 스펙 참고 예시

| IMU 등급 | σ_acc | 자이로 드리프트 | 적합 용도 |
|---|---|---|---|
| 소비자급 (MPU-6050) | ~10mm | ~1.0 °/s | 기본 검증 |
| 스포츠급 (BMI270) | ~3mm | ~0.1 °/s | 운동 추적 |
| 산업급 (ICM-42688) | ~1mm | ~0.01 °/s | 정밀 안정화 |

## 6. 시스템 지연 모델

### 6.1 지연 원인 분해

```
T_total = T_sensor + T_filter + T_comm + T_servo
        ≈ 5ms    + 10ms    + 5ms   + 30ms   = ~50ms (일반적)
```

### 6.2 원형 버퍼 구현

```
latBuf[head] = knee_now
head = (head + 1) % BUF_SIZE

delay_frames = round(T_total / 16.67)   ← 60fps 기준
read_idx = (head - 1 - delay_frames + BUF_SIZE) % BUF_SIZE

knee_sensed = latBuf[read_idx]
```

### 6.3 지연과 안정성

스프링-댐퍼에 지연 T가 있을 때 근사 안정 조건:

```
T < 1 / (2 × ω_n) = 1 / (2 × √22) ≈ 106ms
```

> **주의:** 지연 > 100ms 시 발산 가능성 존재. 시뮬레이터에서 직접 확인 가능.

## 7. 서보 대역폭 제한 모델

### 7.1 각속도 → 선속도 변환

서보 최대 각속도 `ω_max [°/s]`를 바닥 면 선속도로 변환:

```
v_floor_max = ω_max × π/180 × h_knee   [m/s]
```

### 7.2 속도 클램핑

```
if |v_stab| > v_floor_max:
    v_stab = v_floor_max × (v_stab / |v_stab|)
```

### 7.3 서보 선정 기준

HW 스펙 패널의 **최대 각속도 ★** 값보다 서보 사양이 높아야 함:

```
ω_servo_spec > ω_max_measured × 안전마진(1.5~2.0)
```

예: 시뮬레이터에서 최대 60°/s 측정 → 서보 사양 ≥ 90~120°/s 필요

## 8. Monte Carlo 검증

### 8.1 달리기 보행 모델 (Parametric Gait)

```
h_knee(t) = 0.52 + 0.04 × sin(2π × 2.5Hz × t)   [m]
z_knee(t) = -0.02 + 0.03 × cos(2π × 2.5Hz × t)   [m]
```

- 수직 진폭: ±4cm (달리기 중 무릎 높이 변화)
- 전후 진폭: ±3cm (무릎 전후 이동)
- 보행 주파수: 2.5Hz (150 걸음/분 ÷ 60 × 2)

### 8.2 시뮬레이션 흐름

```
for trial in range(N=50):
    initialize: stab_z = -1.0, v_z = 0
    for frame in range(300):  // 5초
        knee_z = gait_model(t) + noise
        target_z = knee_z - d_center
        a = Ks×(target_z - stab_z) - Kd×v_z
        v_z = clamp(v_z + a×dt, ±v_max)
        stab_z += v_z × dt
        error = |stab_z - ideal_z| × 100   // cm
    record max_error, rms_error
compute P50, P95, P99 of max_errors
```

### 8.3 결과 해석

| 지표 | 의미 | 활용 |
|---|---|---|
| P50 최대 편차 | 중간 케이스 최악 오차 | 평균 성능 기준 |
| P95 최대 편차 | 95% 케이스에서 안전 | SLA 설계 기준 |
| P99 최대 편차 | 극단적 최악 케이스 | 안전 마진 설계 |
| 평균 RMS | 평균적 안정화 잔류 오차 | 전반적 성능 |

## 9. HW 스펙 유도 공식

### 9.1 서보 각속도 (부품 선정)

```
θ(t) = arctan(h_knee(t) / d_fwd(t))
ω_pitch = |dθ/dt| ≈ |Δθ / Δt|   [°/s]

서보 사양 ≥ max(ω_pitch) × 1.5~2.0
```

### 9.2 서보 토크 (각가속도 기반)

```
α_max = max(|d²θ/dt²|)   [°/s²]
T_servo = J × α_max + 마찰토크
(J = 프로젝터 모듈 관성 모멘트)
```

### 9.3 프로젝터 렌즈 스펙

**투사비 (Throw Ratio):**
```
TR = h_knee / W_floor
```
TR이 낮을수록 넓게 퍼지는 단초점 렌즈 필요.

**필요 가로 화각:**
```
H_FOV = 2 × arctan(W_floor/2 / d_near)
```
가장 가까운 거리(d_near)에서 최대 화각이 필요.

**필요 세로 화각 (수직 범위):**
```
V_FOV = arctan((d_near + d_depth) / h_knee) - arctan(d_near / h_knee)
```

### 9.4 IMU 최소 사양 역산

```
f_IMU_min = max(ω_pitch_max) / (허용 각도 분해능)   [Hz]
```

예: ω_max = 60°/s, 허용 분해능 0.5° → f_IMU ≥ 120Hz (Nyquist 적용 시 240Hz)
